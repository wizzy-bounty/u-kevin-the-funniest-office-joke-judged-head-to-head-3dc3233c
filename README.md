An entry for the make.fun competition "The Funniest Office Joke, Judged Head to Head": one short line about office life, judged head to head by a model against a published brief.

## How it runs

`main.py` (Python standard library only, deterministic, no network) writes the entry's single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`).
